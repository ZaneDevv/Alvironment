Getting started

Alvironment is a simple code-base engine that allows to create simple 2D and 3D scenarios in C++.

Instalation

The first step before using this environment would be installing it. Therefore, since the environment is on GitHub, we need to use git and run the following command:

git clone --recursive https://github.com/ZaneDevv/Alvironment

After a couple of seconds of waiting, we will see how a new directory was created after the name "Alvironment" in the place we were located after running the command. This directory will contain all the files we need to use this engine. In order to open the project, we need to look for the file Alvironment.sln and open it.

I recommend that once the project is opened, you click on the button "Show All Files" to avoid the messy default Visual Studio's structure and have a cleaner organization with the engine's internal codes and the worlds's codes, with all the .h with its corresponding .cpp file.

Basic main.cpp

If we look into the different files, we will see a file named "main.cpp" which is on charge on running the different simulations we will be creating. Although this file has a lot a content to execute different samples of simulations created to test and showcase the possibilities, the natural and simple structure to follow in this file is just the following:

#include <iostream>
    
#include "alvironment/WorldSetUp.h" // Importing the setUp method
#include "./world/World.h" // Importing the world created

int main()
{
    World myWorld; // Creating a new world instance
    setUp(myWorld); // Setting up the world (executes it automatically)

    std::cin.get();
    return 0;
}

Just by running the imported method setUp(world) and setting an instance of the world you have created as parameter, the world will automatically run.
