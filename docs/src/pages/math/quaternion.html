Quaternion

Struct for calculations among quaternions.

Constants

Quaternion::identity

This constant is the identity quaternion, which is the quaternion 1.

Constructors

Quaternion()

Creates a null quaternion, which is just 0.

Quaternion(double, double, double, double)

Creates a quaternion like \(w + xi + yj + zk\) given:

  • double w: Quaternion's real component
  • double x: Quaternion's first imaginary component \(i\)
  • double y: Quaternion's second imaginary component \(j\)
  • double z: Quaternion's third imaginary component \(k\)
Quaternion(Quaternion&)

Copies the given quaternion and creates a brand new instance with its same arguments.

Operators

Quaternion + Quaternion

Adds the two given quaternion. This is that, for the quaternions \(q_0 = w_0 + x_0i + y_0j + z_0k, q_1 = w_1 + x_1i + y_1j + z_1k\):

\(q_0 + q_1 = w_0 + w_1 + i(x_0 + x_1) + j(y_0 + y_1) + k(z_0 + z_1)\)

Quaternion - Quaternion

Subtracts the two given quaternion. This is that, for the quaternions \(q_0 = w_0 + x_0i + y_0j + z_0k, q_1 = w_1 + x_1i + y_1j + z_1k\):

\(q_0 - q_1 = w_0 - w_1 + i(x_0 - x_1) + j(y_0 - y_1) + k(z_0 - z_1)\)

Quaternion * Quaternion

Multiplies the two given quaternion. This is that, for the quaternions \(q_0 = w_0 + x_0i + y_0j + z_0k, q_1 = w_1 + x_1i + y_1j + z_1k\):

\[ \begin{aligned} q_0 q_1 ={}& w_0 w_1 - x_0 x_1 - y_0 y_1 - z_0 z_1 \\ &+ i(w_0 x_1 + x_0 w_1 + y_0 z_1 - z_0 y_1) \\ &+ j(w_0 y_1 - x_0 z_1 + y_0 w_1 + z_0 x_1) \\ &+ k(w_0 z_1 + x_0 y_1 - y_0 x_1 + w_1 z_0) \end{aligned} \]

Quaternion * number

Multiplies a quaternion by a scalar. This is that, for the quaternions \(q = w + xi + yj + zk\) and the scalar α:

\(\alpha q = \alpha w + \alpha x i + \alpha y j + \alpha z k\)

Quaternion / number

Divides a quaternion by a scalar. This is that, for the quaternions \(q = w + xi + yj + zk\) and the scalar α:

\(\frac{1}{\alpha} q = \frac{w}{\alpha} + \frac{x}{\alpha} i + \frac{y}{\alpha} j + \frac{z}{\alpha} k\)

-Quaternion

Invers the sign of all the quaternion's numbers:

\(-q = -1q = -w - xi - yj - zk\)

Quaternion == Quaternion

Checks if the given two quaternions are the same. Two quaternions are the same if all its components are the same.

\(q_0 = q_1 \iff w_0 = w_1 \wedge x_0 = x_1 \wedge y_0 = y_1 \wedge z_0 = z_1\)

Methods

static Quaternion createByWAndAxis(double, const Vector3D&)

Creates a new quaternion taking the given scalar as w axis and the vector's axes as imaginary components.

static Quaternion normalize(const Quaternion&)

Normalizes the given quaternion making its magnitude to be one. This is:

\(q' = \frac{q}{|q|} \iff |q| \ne 0\)

static Quaternion conjugate(const Quaternion&)

Gets the conjugate of the given quaternion. This is \(q^* = w - xi - yj - zk\).

static Quaternion inverse(const Quaternion&)

Gets the inverse of the given quaternion. The inverse of a quaternion is a quaternion \(q^{-1}\) such that \(qq^{-1} = 1\).

\(q^{-1} = \frac{q^*}{|q|^2}\)

static Quaternion power(const Quaternion&, double)

Powers the given quaternion to the given scalar. This is, representing a the quaternion in polar coordinates:

\(q^n = \left(|q|[\cos(\theta) + u \sin(\theta)]\right)^n = |q|^n\left(\cos(n\theta) + u \sin(n\theta)\right) \)

static Quaternion slerp(const Quaternion&, const Quaternion&, double)

Interpolates spherically the given two quaternions according to alpha. This is the quaternion's version of linear interpolation, since quaternions are spherical and lienar interpolations go in a stright line, we need to use a spherical path:

\(q = \left(q_1 q_0^{-1}\right)^\alpha q_0\)

float getMagnitude()

Gets the magnitude of the quaternion. This is that, for a quaternion \(q = w + xi + yj + zk\):

\(|q| = \sqrt{w^2 + x^2 + y^2 + z^2} = \sqrt{qq^*}\)

float getAngle()

Gets the angle of the quaternion. This is that, for a quaternion \(q = w + xi + yj + zk\), the angle is:

\(\theta = 2\arccos\left(\frac{w}{|q|}\right)\)

Vector3D getAxis()

Gets the axis of the quaternion. This is that, for a quaternion \(q = w + xi + yj + zk\), the axis is the vector \(\begin{pmatrix} x \\ y \\ z \end{pmatrix}\).

double getW() const

Gets the quaternion's w axis.

void setW(double)

Sets the quaternion's w axis.

double getX() const

Gets the quaternion's x axis.

void setX(double)

Sets the quaternion's x axis.

double getY() const

Gets the quaternion's y axis.

void setY(double)

Sets the quaternion's y axis.

double getZ() const

Gets the quaternion's z axis.

void setZ(double)

Sets the quaternion's z axis.
