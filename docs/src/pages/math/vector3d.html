Vector3D

Struct for calculations among tridimensional vectors.

Constants

Vector3D::zero

This constant is the null vector \(\vec{0}\), which is the vector \(\begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix}\).

Vector3D::one

This constant is a vector whose all components are 1: \(\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix}\).

Vector3D::i

This constant the is vector \(\hat{i}\), which is the unit vector \(\begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}\).

Vector3D::j

This constant the is vector \(\hat{j}\), which is the unit vector \(\begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix}\).

Vector3D::k

This constant the is vector \(\hat{k}\), which is the unit vector \(\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}\).

Constructors

Vector3D()

Creates a null vector, equivalent Vector3D::zero.

Vector3D(double, double, double)

Creates a vector with the vector \(\begin{pmatrix} x \\ y \\ z \end{pmatrix}\) given:

  • double x: Vector's x component
  • double y: Vector's y component
  • double z: Vector's z component
Vector3D(Vector3D&)

Copies the given vector and creates a brand new instance with its same arguments.

Operators

Vector3D + Vector3D

Adds the two given vectors. This is, for vectors \(\vec{v}\) and \(\vec{w}\):

\(\begin{pmatrix}v_x \\ v_y \\ v_z\end{pmatrix} + \begin{pmatrix}w_x \\ w_y \\ w_z\end{pmatrix} = \begin{pmatrix}v_x + w_x\\ v_y + w_y \\ v_z + w_z\end{pmatrix}\)

Vector3D - Vector3D

Subtracts the two given vectors. This is, for vectors \(\vec{v}\) and \(\vec{w}\):

\(\begin{pmatrix}v_x \\ v_y \\ v_z\end{pmatrix} - \begin{pmatrix}w_x \\ w_y \\ w_z\end{pmatrix} = \begin{pmatrix}v_x - w_x\\ v_y - w_y \\ v_z - w_z\end{pmatrix}\)

Vector3D * number

Multiplies a vector by a scalar. This is that, for the vector \(\vec{v}\) and the scalar α:

\(\alpha \vec{v} = \begin{pmatrix} \alpha v_x \\ \alpha v_y \\ \alpha v_z\end{pmatrix}\)

Vector3D / number

Divides a vector by a scalar. This is that, for the vector \(\vec{v}\) and the scalar α:

\(\frac{1}{\alpha} \vec{v} = \begin{pmatrix} \frac{v_x}{\alpha} \\ \frac{v_y}{\alpha} \\ \frac{v_z}{\alpha} \end{pmatrix}\)

-Vector3D

Multiplies the vector by -1. That is: \(-\vec{v} = -1\vec{v} = \begin{pmatrix} -v_x \\ -v_y \\ -v_z\end{pmatrix}\).

Vector3D == Vector3D

Checks if two vectors are the same. That is:

\(\vec{v} = \vec{w} \iff v_x = w_x \wedge v_y = w_y \wedge v_z = w_z\)

Methods

static double dot(const Vector3D&, const Vector3D&)

Computes the dot product \(\vec{v} \cdot \vec{w}\) between the given two vectors. That is:

\(\vec{v} \cdot \vec{w} = \vec{v}_x \vec{w}_x + \vec{v}_y \vec{w}_y + \vec{v}_z \vec{w}_z = \|\vec{v}\|\|\vec{w}\|\cos(\theta)\)

static Vector3D cross(const Vector3D&, const Vector3D&)

Computes the cross product \(\vec{v} \times \vec{w}\) between the given two vectors. That is:

\(\vec{v} \times \vec{w} = \det\begin{pmatrix} \hat{i} & \hat{j} & \hat{k} \\ \vec{v}_x & \vec{v}_y & \vec{v}_z \\ \vec{w}_x & \vec{w}_y & \vec{w}_z \end{pmatrix} = \begin{pmatrix} \vec{v}_y \vec{w}_z - \vec{v}_z \vec{w}_u \\ \vec{v}_z \vec{w}_x - \vec{v}_x \vec{w}_z \\ \vec{v}_x \vec{w}_y - \vec{v}_y \vec{w}_x\end{pmatrix}\)

static Vector3D hadamard(const Vector3D&, const Vector3D&)

Computes the hadamard product \(\vec{v} \circ \vec{w}\) between the given two vectors. That is:

\(\vec{v} \circ \vec{w} = \begin{pmatrix} \vec{v}_x \vec{w}_x \\ \vec{v}_y \vec{w}_y \\ \vec{v}_z \vec{w}_z \end{pmatrix}\)

static Vector3D lerp(const Vector3D&, const Vector3D&, double)

Computes a linear interpolation \(lerp(\vec{v}, \vec{w}, t)\) between the given two vectors and the alpha parameter. That is:

\(lerp(\vec{v}, \vec{w}, t) = \begin{pmatrix} \vec{v}_x (1 - t) + \vec{w}_x t \\ \vec{v}_y (1 - t) + \vec{w}_y t \\ \vec{v}_z (1 - t) + \vec{w}_z t \end{pmatrix}, t \in [0, 1]\)

  • const Vector3D& v: First vector, where the linear interpolation begins.
  • const Vector3D& w: Second vector, where the linear interpolation ends.
  • double t: Alpha parameter which represents how much the interpolation has progressed.
static Vector3D normalize(const Vector3D&)

Normalizes the vector to have magnitude of 1. That is:

\(\hat{v} = \frac{1}{\|\vec{v}\|} \vec{v} \iff \|\vec{v}\| \ne 0\)

double getMagnitude() const

Computes the magnitude/norm \(\|\vec{v}\|\) of the vector. That is:

\(\|\vec{v}\| = \sqrt{\vec{v}_x^2 + \vec{v}_y^2 + \vec{v}_z^2} = \sqrt{\vec{v} \cdot \vec{v}}\)

double getX() const

Gets the x component of the vector.

void setX(double)

Sets the x component of the vector.

double getY() const

Gets the y component of the vector.

void setY(double)

Sets the y component of the vector.

double getZ() const

Gets the z component of the vector.

void setZ(double)

Sets the z component of the vector.
