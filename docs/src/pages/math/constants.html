constants.h

This file provides some useful mathematical constants you can be using in your programs.

Constants

ONE_DEGREE_IN_RADIANS

This constant represents \(\frac{\pi}{180}\), which is the radians equivalent to 1º.

RIGHT_ANGLE

This constant represents \(\frac{\pi}{2}\), which is the radians equivalent to 90º.

PI

This constant is just the number π.

TAU

This constant represents τ = 2π, which is the radians equivalent to 360º.
