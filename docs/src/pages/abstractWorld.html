Abstract World

To create a new world able to run your simulation, you require some features given by the class Abstract World which can be included from alvironment/AbstractWorld.h.

#pragma once

#include "alvironment/AbstractWorld.h"

class MyWorld : public AbstractWorld
{
public:
    void initialize() override;
    void update(double) override;
}

Methods

void initialize()

Initializes the world and commences the simulation. This method is fired automatically with the setUp() method

You should use this mehtod to set up the world's scenario, create the environment and decide the window's parameters. A simple example of code would be the following:

#include "MyWorld.h"

void MyWorld::initialize()
{
    WindowProperties properties(500, 500, "My World", true);
    this->environment.emplace(&properties);
}
void update(double)

Main world's loop. This method is automatically fired every frame by the Environment class. Furthermore, it offers a Δt as double parameter which corresponds to how much time has passed from the last frame to the current one.

Variables

std::optional<Environment> environment

This is the environment to create in the initialize() method
