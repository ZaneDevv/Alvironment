Circle2D

Circles can be created automatically by creating an instance of this class and do not have necessarily to care about the vertices or indices.

Constructors

Circle2D(const char*, const char*)

Creates a new 2D circle object with the given shaders.

  • const char* vertexShader: Path where the vertex shader is located.
  • const char* fragmentShader: Path where the fragment shader is located.
Circle2D()

Creates a new 2D circle object.

Methods

void render()

Renders the object on screen. This method should only be used by the class Environment2D.

void setUpBuffers()

Sets up all the information the GPU requires to render the object. This method should only be used by the class Environment2D when the object is added.

void updateVertices()

Computes the actual vertices after applying all the required transformations. This method should only be used by the class Environment2D when the object is added and by this class itself when the transformation matrix changed.

double getTheta() const

Gets the angle the object is rotated.

void setTheta(double)

Sets the angle the object is rotated to the argument.

Vector2D getScale() const

Gets the scale of the object.

void setScale(const Vector2D&)

Sets the scale of the object.

Vector2D getPosition() const

Gets the position of the object.

void setPosition(const Vector2D&)

Sets the position of the object.
