Window properties

In order to have a window on a screen, it is important to clarify certain properties such as the dimensions or title of it. To set this

Constructors

WindowProperties(u16_t, u16_t, const char*, bool)

Creates a set of settings for the window with the following arguments:

  • unsigned short width: Window's width
  • unsigned short height: Window's height
  • const char* title: Window's title
  • bool resizeable: Window's title
